# Prebuilt distributions

Normal users should use the prebuilt archive for their operating system.
They do **not** need Python, pygame, Pillow, PyInstaller, or a local build step.

## Windows x64

`prebuilt/windows-x64/BreakoutForge-vX.Y.Z-windows-x64.zip`

The matching `.sha256` file is committed beside the archive.

These files are generated by GitHub Actions only after:

- complete pytest / release E2E
- data and license checks
- PyInstaller onedir build
- packaged executable acceptance
- image-stage loading through bundled Pillow
- ZIP extraction and re-acceptance

Formal GitHub Releases attach these exact repository files instead of rebuilding them.
